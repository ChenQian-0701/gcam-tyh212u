# v0.1.0-alpha.1 — TYH212U compatibility research

Initial public-source export of the device-specific LSPosed adapter. Exact TYH212U/ARES/API30/BSG-APK checks are added before hook installation. The public build uses standard SDK tooling, declaration-only compile stubs and external signing keys; duplicated hook registration was removed and Xposed hook return signatures corrected.

The same-exposure six-frame baseline and historical evidence are preserved. Full bracketing, standard-HDR repeatability and post-shot AE recovery remain incomplete. This release is **experimental**, not a general Unisoc port.

See `docs/validation.md` for checks actually run on this public-source export. Historical device results are identified separately. Module APKs use a new publication signing key; existing same-package private-research installations signed with a different key cannot be updated directly. Preserve old settings/module before changing installation.

No GCam APK, native library, private key or raw phone dump is included. Each installable module asset is accompanied by SHA-256. General porting methods/tools are in https://github.com/ChenQian-0701/gcam-unisoc-research .
