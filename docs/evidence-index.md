# Evidence index

Historical phone results precede the public-source export and must not be advertised as a full regression of the changed public module. [Publication validation](validation.md) reports new checks separately.

- `evidence/historical/2026-10-30-stage26-verdict.json`: historical 6/6 and 2/2 enhanced sessions; standard saved 1 image but did not recover in the recorded window. Button-enabled fields were later found imperfect, so interpret with shot/output logs.
- `docs/experiments/`: selected, sanitized research notes. Many intermediate claims were superseded; their named original work/log files are not all redistributed.
- `evidence/quality/summary.json`: aggregate measurements from 20 user-labelled JPEGs; primary analysis uses stable-EXIF pairs 3–10. No GPS, source paths or full photographs are included.
- `evidence/quality/rois.json`: ROI coordinates in the historical reference image; meaningful only for that scene.
- `evidence/quality/comparison-preview.png`: native-pixel crops from pair 9, off ISO937 / enhanced ISO931; labels/composition only, no pixel enhancement.
- `evidence/quality/noise-summary-zh.png`: chart of SDR output fluctuations.

A stage-note filename is not a performance guarantee. There are no raw GCam/native libraries or complete decompiled classes in this export.
